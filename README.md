# EduFocus 🎓
> Dars vaqtida diqqatni boshqarish va o'quvchilar telefonini intizomli nazorat qilish platformasi.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy)

## Imkoniyatlar
- 👨‍🏫 **O'qituvchi**: Ro'yxatdan o'tish, dars sessiyasi yaratish, real-vaqtda o'quvchilar ro'yxatini va holatini kuzatish, telefonlarni bloklash va dars tugagach ruxsat berish.
- 📱 **O'quvchi**: Hech qanday ilova o'rnatmasdan, faqat QR kodni skaner qiladi, ismini kiritadi va dars rejimiga tushadi.
- ⚡ **Real-vaqt (Socket.io)**: O'qituvchi ruxsat berishi bilan bir zumda barcha o'quvchilar ekranida holat o'zgaradi.
- 👁️ **Fokus nazorati**: O'quvchi sahifadan chiqib ketishga urinsa (Page Visibility), darhol o'qituvchi monitorida ogohlantirish ko'rsatiladi.

## O'rnatish va Ishga Tushirish

```bash
git clone https://github.com/khushbakoff/edufocus.git
cd edufocus
npm install
npm start
```
Brauzerda: `http://localhost:3000`
